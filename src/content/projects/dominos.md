## Context

### Project Vision

Users have found the Domino's franchise website difficult to navigate, which often deters them from completing orders. Recognizing these issues, we've proposed a redesigned website tailored specifically for the Ann Arbor location. While the solution may appear visually simple, creating a seamless and user-friendly experience requires careful strategy and thoughtful design.

![Redesigned Domino's Ann Arbor website homepage](/julian-portfolio/images/dominos/01.webp)

### Challenges

1. Create a minimalistic UI while keeping food as the focus.
2. Design a cohesive interface for familiar and unfamiliar users.
3. Provide a linear purchasing experience.
